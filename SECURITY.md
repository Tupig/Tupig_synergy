# Security Policy / 安全策略

## Scope / 范围

This policy covers the code in this repository and the packages built from it,
including inherited upstream code that ships in those builds.
本策略覆盖本仓库中的代码，以及由这些代码构建出的安装包（包括随构建发布的上游代码）。

The detailed controls are in [`docs/security.md`](docs/security.md).
具体控制措施见 [`docs/security.md`](docs/security.md)。

## Supported Versions / 支持版本

| Version | Supported |
| ------- | --------- |
| 1.21.x and current `main` | :white_check_mark: |
| older release lines | :x: |

1.21.x 与当前 `main` 受支持。更早的发布线不受支持。

## Reporting a Vulnerability / 上报漏洞

**Do not open a public issue for security problems.** Use GitHub private
vulnerability reporting (repository **Security → Report a vulnerability**).
That feature is enabled on this repository.

**请勿用公开 issue 上报安全问题。** 请使用 GitHub 私密漏洞报告（仓库
**Security → Report a vulnerability**）。本仓库已开启该入口。

We aim to acknowledge a report within a few days and will agree a fix and
disclosure timeline with you.
我们会在数日内确认，并与你约定修复和披露时间。
