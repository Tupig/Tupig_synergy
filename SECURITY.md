# Security Policy / 安全策略

## Scope / 范围

This policy covers the code in this repository and the packages built from it, including upstream code that those packages still contain.

本策略覆盖本仓库里的代码，以及用这些代码打出的安装包，包括安装包里仍然带有的上游代码。

The controls are written in [`docs/security.md`](docs/security.md).

具体控制措施写在 [`docs/security.md`](docs/security.md)。

## Supported Versions / 支持版本

| Version / 版本 | Supported / 是否支持 |
| --- | --- |
| 1.21.x and current `main` / 1.21.x 与当前 `main` | Yes / 是 |
| Older release lines / 更早的发布线 | No / 否 |

A supported line still receives defect fixes from this repository. Older lines do not.

受支持的版本仍会收到本仓库的缺陷修复。更早的发布线不再修改。

## Reporting a Vulnerability / 上报漏洞

**Do not open a public issue for a security problem.** Use GitHub private vulnerability reporting: repository **Security → Report a vulnerability**. That entry is enabled here.

**不要用公开 issue 上报安全问题。** 使用 GitHub 私密漏洞报告：仓库 **Security → Report a vulnerability**。本仓库已打开这个入口。

We aim to acknowledge a report within a few days, then agree with you when the fix ships and when it can be discussed in public.

我们会在几天内确认收到报告，再和你约定修复何时发布、何时可以公开讨论。
